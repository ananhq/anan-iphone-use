当前补充：[跟手修正](avatar-responsive.zh-CN.md)已移除全部闲置道具，输入时保留体感，反馈缩短至约 0.6 秒，并改用优化的紧凑区域刷新。下方保留 0.9.1 的原验收记录。

## 运行时修改前定义的验收

- 点击/双击：向前探身回弹、青色光标与一次/两次扩散圆环。长按：压低专注眼神、
  琥珀色圆盘和呼吸光环。拖动/路径：方向倾斜、青色光标与最多六个近期轨迹点。
- 滚动：明显扫视、三张蓝色移动卡片。打字：脸部律动、圆角迷你键盘和跳动键帽。
  键盘/媒体键：大号紫色键帽按压回弹。输入中断：不对称疑惑眼神与琥珀色问号，
  不把输入发送结束画成手机任务完成。
- 短动作至少明显展示一秒，不延迟输入；执行中持续显示、结束后平滑消退。新动作
  短暂交叉过渡并替换旧动作，不积压输入或动画。有界动作幅度、过渡、图元数、
  尾迹存储和每帧栈使用。
- 可选等待小场景：连续六秒没有输入或本地触摸后，偶尔出现上升的蓝色气泡并变成
  小灯泡。这是趣味等待，不是真实模型思考状态。状态轮询不触发输入动画；实体键
  和 MCP 停止继续通过现有 UI 立即退出。
- 保留上游表情表/代码和普通待机像素；在本地图元适配中增强脸部位移/缩放。
  道具复用图元和扫描行区间，不引入位图帧、全屏画布、逐像素浮点特效或全屏闪烁。
- 根据实际绘制范围记录两眼和第三个道具区的新旧边界。预定义合成场景逐帧核对
  各类动作、退出、快速替换、等待/触摸过渡的局部刷新与全帧等价；要求彩色道具、
  不同画面、短动作可见、待机保留、连续有限变换、无残影和无图元溢出。
- 复用实体停止/授权、UI、worker/HID 时序、BLE/无线、DMA、IMU、模拟烧录和
  源码提供场景；核对目标栈、固定 SDK 编译/打包与嵌入源码一致，并生成原生预览。

实机观感、流畅度、输入共存与停止延迟仍需另行授权验收。用户对上一版表情的
正面反馈属于用户反馈，不是本次新候选的实测数据。
