# 表情绘制修正

[English](avatar-performance.md) · 简体中文

这是 0.8.1 历史修正记录。用户随后同意[0.9.0 上游移植](avatar-upstream.zh-CN.md)，已用原版表情表和图元绘制替换这里的近似实现。

用户反馈 `0.8.0-avatar` 动作不明显、帧率低。未确认实际镜像哈希、显示耗时和
实机通知轨迹。源码对比确认了实际差距：

- 原项目空闲单眼约 72×168px、眼心距 210px；当前为 104×144px、眼心距
  144px，缺少眉毛和完整单击/双击/长按表情时间轴，并未忠实复现。
- 当前候选像素逐点执行变换、min/max、除法和三次颜色取整；原项目主要绘制
  几何跨度/图元，并分别清除每只眼睛新旧区域。
- 当前把双眼并为一个区域，分 16 行 DMA 传输；原项目分别处理双眼区域，
  约 16.667ms 调度。原项目记录的帧率不能当成本固件的实测结果。

## 实现前定义的独立修正

在等待用户决定是否引入上游 AGPL 表情代码时，保持现有几何和 GPL 源码，独立
修正性能。不引入上游实现，不改输入/工具/停止/IMU 配置。

- 旋转圆角矩形拆成两个核心矩形和四个圆角，以扫描行求交，仅逐行计算变换，
  连续白色跨度批量填充并加灰边，移除逐像素浮点/颜色换算。
- 每只眼睛分别更新新旧区域并集；重叠区域仍绘制双眼。进入/退出保留整屏刷新，
  DMA 完成状态未知仍禁止复用。保留 30fps 目标，实际测量后再决定是否提高。
- 活跃期间每五秒输出有界的动画更新/实际绘制次数、绘制平均/最大耗时，不含
  输入文本、坐标、token、设备身份；加入统计不代表已执行设备测量。
- 修改运行时代码前定义：零角度/旋转/眼睑/圆角解析形状、分眼区域/整帧等价、
  合成时间窗口统计；复用 UI/停止/IMU/HID/无线/模拟烧录/栈检查、固定编译打包
  与原生预览。
- 另行授权的设备验收：实际更新/绘制节奏、输入共存、快速触摸与 MCP 动作、
  停止和设置导航。原表情移植仍取决于用户的许可决定。
