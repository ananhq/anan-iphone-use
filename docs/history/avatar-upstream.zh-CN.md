# 上游表情引擎移植

[English](avatar-upstream.md) · 简体中文

0.9.1 的[输入操作层](avatar-activity.zh-CN.md)增加较大脸部动作与少量彩色道具，保留这里的上游引擎和普通待机风格。

维护者于 2026-10-15 同意引入 AGPL-3.0-or-later 引擎，替代 0.8.x 独立近似的控制表情。
来源为 Trentct/m5stack-stopwatch-avatar，固定提交
`204963257cb4dc2f3d7501eff900897bac55ef82`。

## 实现前定义的验收

- 保留全部十二种表情表、关键帧时间、缓动、眨眼、眉毛、投影和交互计算。
  待机眼使用上游 1000 单位设计，约 72 × 168 像素，两眼中心相距 210 像素。
- 绘图和计时对接原生 ESP-IDF，不引入 Arduino、M5Unified、M5GFX、全屏画布、
  屏幕重新初始化或 USB/BLE 输入改动。使用有界图元命令和扫描行区间，保留绘制
  顺序、眼睑遮罩和眉毛线条；命令溢出时拒绝该帧。
- 离线场景覆盖全部表情、有界内存、非空且不同的画面、眉毛图元、局部/全帧刷新
  等价和 RGB565 字节序。短暂且已结束的 MCP 动作仍播放完整表情；连续输入不应
  每帧重启第一个关键帧。
- 单击开心、双击惊讶、长按 650ms 生气；左右滑切换表情，上滑惊讶、下滑困倦。
  拖动沿用上游滑动过渡；倾斜复用可选 BMI270 适配。表情触摸不向手机发送输入。
- 新的“开始控制”重置表情与事件基线；任一正面实体键立即撤销输入、返回首页并
  消费至松开。保留读取错误、断连和 MCP 撤销，不更改描述符、worker 延时、授权
  比较、传输或供电。
- 目标为上游 16.667ms 节奏，计入已耗时，保留低优先级任务和五秒更新/绘制耗时
  诊断。这不是设备 FPS 保证；打包前检查目标编译器的栈预算。
- 保留原许可和来源声明、明确修改。HTTP/HTTPS 配置页均提供设备内源码下载，
  包含本次构建的源码、配置、许可、构建脚本、依赖锁和安装说明。按明确白名单
  归档，排除凭据、设备生成配置、.git、机器路径、日志和无关笔记；嵌入/打包前
  离线验证可重复生成及内容。

设备验收另需授权：对比实际待机比例、单/双击/长按/滑动、倾斜方向与中立点、
各类 MCP 动作和快速切换；记录实际更新/绘制耗时、输入共存、实体停止延迟和
源码下载。编译及合成预览不代表完成这些设备验收。
