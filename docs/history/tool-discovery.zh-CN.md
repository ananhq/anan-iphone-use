# iPhone 输入工具的发现

[English](tool-discovery.md) · 简体中文

`0.7.3-discovery` 仅修改元数据：七个工具描述增加简短中英文任务词，服务简介
柔性建议在规划多步控制前先浏览整组。不新增工具、改变 schema、提供直接启动
App 接口或修改输入执行、授权、通道、客户端代码。

修改前定义验收：解析内嵌工具 JSON；严格保持名称/顺序、schema、annotations；
保留执行器/HID/射频/配置输入；服务简介不超过 500 字符；任务词按各工具职责
分配；保留必要时序、ASCII、坐标、焦点和不重放约束；编译/打包并核对源码/镜像
manifest。源码/静态证据不证明模型发现或手机操作成功。本范围不新增单元测试，
不执行设备或真实模型调用。

| 工具 | 任务词 |
| --- | --- |
| `device_status` | 连接、输入就绪、物理控制授权、忙碌状态 |
| `tap` | 点击可见应用图标/搜索结果、按钮、链接、设置开关 |
| `drag` | 滑动/导航页面、拖动对象、画一笔或签名 |
| `press_key` | 主屏幕/Spotlight 打开应用流程、导航、确认、编辑、媒体 |
| `type_ascii` | 在已聚焦输入框填写 ASCII 应用名/搜索词、网址、消息、表单 |
| `scroll` | 滚轮浏览列表、网页、信息流 |
| `stop` | 停止/取消手机输入、撤销控制 |

打开 App 仍由客户端规划 UI 流程：`press_key` 进入主屏幕或 Spotlight，按需
`type_ascii` 输入 ASCII 搜索词，再 `tap` 点击观察到的图标/结果。ASCII 无法
注入中文名称。固件不接受 bundle ID、不查找 App、不截图、不报告 App 成功。
选目标前观察，操作后再次确认。

已检查的 Anan 按工具名、描述及参数元数据做关键词排序，不为 MCP 添加原生
工具的中文别名。默认五项是结果分页大小，不是服务工具数量。完整了解一组时，
`tool_search` 使用空 `query`、当前客户端上下文中的准确 group、`limit: 10`；
需要时继续 `nextOffset`。非空关键词即使提高 limit 仍可能过滤部分工具。搜索
只返回简介，`tool_describe` 读取选定完整 schema，再 `tool_call`；可见且未变化
的定义可以复用。这是建议，不是自动加载或授权，本次不修改 Anan。

刷入本候选后刷新客户端工具目录。Anan 中自定义服务描述会覆盖服务端简介，
有需要时单独更新该自定义文字。限定 `apple` 的搜索应扩大到 MCP 组。客户端
可能缓存目录，不能仅凭升级固件就认为模型已收到新描述。
