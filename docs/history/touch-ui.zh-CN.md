# 触屏 UI 决策

[English](touch-ui.md) · 简体中文

## BLE 重连状态：修改前界定范围

用户反馈手机先显示蓝牙已连接，StopWatch 很久后也显示连接。既有首页标签使用
完整 HID 就绪条件，即使 BLE 链路已连接也提示重新配对。用现有模型字段分别显示
未连接、链路已连接/等待输入及输入就绪；保留输入选择、加密/订阅要求、开始按钮
门槛、授权、时序和 BLE 回调。显示修正不代表已确定或缩短实际重连延迟。修改前
定义等待和已连接未就绪的双语预览，执行既有布局/停止检查及目标编译/栈/源码
检查。本阶段不授权新增设备操作或提交。

用户因长按菜单和 USB/MCP 命名操作费劲、理解困难，要求触屏为主；随后明确要求中英
双语、设备内切换。此范围允许原生触摸/UI 实现，不包含新烧录、手机操作、模拟器、
provider 或 E2E 执行；不改 [Anan](https://anan.sh)。

## 原触屏实现前范围（历史）

- StopWatch CST820B，I2C0 SDA47/SCL48、地址0x15、GPIO13中断、M5IOE1
  PYG4/bit3复位。固定出厂参考从0x00读七字节，包含指针数、0/2事件、12位x/y。
  使用原生 IDF API、独立任务有界轮询，不引入出厂 UI 或 LVGL。
- 主页：连接状态、“Anan直连／MCP应用”来源按钮、一个开始/停止主按钮、设置。
  两种来源都用同一根 USB 线，默认 ANAN1/报告语义保留，直连授权仍由 Anan 管理。
- 配对页：手机地址、匹配验证码、明确“确认配对”按钮、进度及手机导入后再返回的说明。
  密钥/文字输入留在手机，重置独立放置，需按住两秒物理确认。
- 设置：简体中文/English、MCP配置、重置、返回。语言与身份分开记忆，授权/会话/动作
  不持久化。
- 原始实体按键仍停止活动/已授权输入。控制时触屏先停止并消费本次接触；导航/启用需
  在当前已显示按钮上重新点按/松开，持续接触或旧画面不能启用。触摸失败保留实体键
  备用；不使用 I2C 的实体停止任务保持独立。
- 沿用 DMA 条带绘制，圆角按钮和统一命中区域；中文只取固定 Noto Sans SC 字形子集，
  ASCII保留自写字形。保留完整 SIL OFL，不改变项目许可证、不加运行时图形框架。

## 预定义检查

| 检查 | 所需证据 |
| --- | --- |
| 静态/构建 | 固定构建/打包、原 USB/ANAN1/动作源码不变量、中英标签/字体覆盖、准确字体许可/哈希、有界 I2C/任务/布局检查 |
| 文档视觉 | 用同一布局/文本/字体资产生成独立图片，检查圆屏裁切、双语、标签及按钮区域；不是设备执行 |
| 触摸硬件 | 另行授权真机坐标、按下/松开/持续触摸、轮询/错误恢复及所有可见按钮 |
| 输入/停止 | 拖动/输入时实体键/触摸停止，同次接触不能重启，无重放/隐藏来源切换，测量延迟 |
| 语言/配置 | 语言切换/重启/升级记忆、验证码确认、iPhone实际信任/配置导出、重置确认 |
| 故障 | 触摸不可用、陈旧读取、手指持续按住、画面变化：不误启用，实体备用/停止可用 |

真机检查在另行授权且实际观察前均待验证，不在实现后补单元测试。首方模块保持双语
文档，原来源缺口保留。

## 已实现的开发阶段

候选0.2.0实现布局、设备语言记忆及双语手机页。触摸读取超时20ms，任务间隔10ms；
原始实体停止任务保持5ms及更高优先级。读取失败消费该次接触，松开用最后有效按下
坐标，授权变更与新显示画面代际检查串行；绘制/语言保存不在实体停止处理内。
硬件触摸、语言记忆仍未验证。

静态预览：开发环境安装 Pillow12.3.0，执行 `python tools/render_ui.py`。只编译
`ui_layout.c` 成文档布局导出器，使用虚拟验证码/指纹及同一位图资产，输出至被忽略的
`build/ui-previews/`；不操作固件、手机、provider或 HID。执行
`tools/generate_ui_font.py FONT_FILE` 可用 THIRD_PARTY 中固定来源/哈希字体重建中文
子集，字形保留 OFL。

用户确认移除三分钟授权时限。候选 `0.2.1-mcp` 改用不持久化的布尔授权，
持续至停止/拔线/重启，仍保留模式切换、身份维护、显示故障撤销。启用时显示
“控制已开启”。本次允许编译/打包、共用布局双语预览和源码审查；超过180秒
控制及撤销/重启行为仍待真机验证。

HTTP 候选 `0.3.0-mcp` 将配对/重置提示改为配置导入，不再要求证书信任。
开始控制检查 HTTP 或 HTTPS MCP 就绪；实体/触屏停止和同次接触不再启用保持。

候选 `0.4.0-mcp` 移除 Anan直连/MCP来源选择，开机直接进入 MCP。首页显示
MCP控制，仅保留开始/停止与设置；配对、语言和实体/触屏停止保留，当前静态预览20个场景。

## 当前大按钮布局

候选 `0.7.6-touch-ui` 用最多三项的菜单、上级返回和 72–96px 按钮替换拥挤的
设置/输入页；仅首页显示粗略的电压电量估算，控制中首页只突出停止。普通点击
围绕原目标容忍 10px 抖动，重置长按保持严格边界。按下/长按反馈和电量刷新
不取消手势。前文为历史记录，本阶段见[当前范围与预定义检查](touch-usability.zh-CN.md)。
实机易用性和电量准确性仍待验证。

当前 `0.8.0-avatar` 控制画面仍为纯黑无字眼睛。倾斜/触摸改变视线，触摸不向手机
发送输入，也不停止控制。任一正面实体键停止并返回首页，读取错误撤销保护保留。
见[可交互表情范围](avatar.zh-CN.md)，前述停止布局属于历史记录。
