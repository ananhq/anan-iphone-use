# 大按钮界面与首页电量

[English](touch-usability.md) · 简体中文

实现前已约定：接入审阅过的 466px 圆屏原生设计，仅在首页显示估算电量。
复用现有条带渲染器和字体，保留实体停止、新触摸授权、HID、MCP 与客户端行为；
不增加运行依赖，不调整供电策略。

## 预先定义的验收

- 所有可见按钮至少高 72px，位于圆屏内，点击区域不重叠，中英文文字均能容纳。
  首页主按钮高 96px；菜单最多三项加返回。
- 设置进入输入方式、连接与配网或更多设置；更多进入语言、蓝牙重置或 MCP 重置。
  返回回到上一级；退出配对关闭配对窗口和热点，不授予输入；完成回到首页。
- 控制中首页突出停止，不再显示容易误解的设置按钮。触摸或原始实体按键仍先停止，
  并消耗本次触摸/按键；停止、重置、切换输入和重连均不自动恢复授权或重放动作。
- 普通点击必须从按钮内部开始，后续允许围绕原目标抖动 10px，不跳转到相邻按钮。
  重置仍需在严格区域内持续长按两秒；读取失败、旧版本界面、控件变化或实体按键
  取消手势。按下/进度反馈和电量变化本身不能取消点击。
- 复用 M5PM1 I2C 设备，只读 0x22 开始的两个字节，小端毫伏值，限制超时，
  不新增供电寄存器写入。失败/无效采样显示未知，不冒充零电量或保留过期读数。
  自编粗略算法将 3.3–4.2V 线性映射为 0–100%，取整到 5%；2.5–4.5V 以外无效。
  这只是未经校准的电压估算，并非电量计或续航预测；充电、负载和温度会影响结果。
  界面明确标注“约”。
- 在低优先级屏幕任务中最多每 15 秒采样一次，仅首页且无触摸/实体按键按下时执行。
  电量和按压反馈不改变授权版本或停止任务；不能凭 USB 连接推断正在充电。
- 修改固件前定义宿主布局/点击、电量估算和实际设备控制函数验收脚本；随后执行
  固定 SDK 编译打包、已有离线 HID/无线/烧录检查、共用布局的中英文渲染、字体/二维码
  检查，以及传输、报告、安全和存储源码不变核对。
- 实机另行授权验收：导航和边缘点击、重置短按/长按、抖动与取消、输入时触屏/按键停止
  且同次触摸不能开启、语言持久化、热点与二维码、电池和 USB 供电下的读数、波动和触摸
  响应。静态渲染/宿主脚本不证明实机成功。

## 硬件与来源

M5Stack [M5PM1](https://github.com/m5stack/M5PM1/tree/be9a5456c007c333e7ac963f33bfde1ffa5d82ee)
的 `docs/M5PM1_Datasheet_EN.pdf` ADC Register 节和 `src/M5PM1.h/.cpp` 确认只读电池电压
寄存器 0x22/0x23 及毫伏单位。新的 C 适配器使用寄存器事实，没有复制厂商库、类或电量算法。
保留完整 M5PM1 MIT 声明，原有板级代码来源缺口仍未解决。

## 仅按钮触屏停止：实现前约定的后续修改

用户明确要求用按钮停止替代触碰任意位置停止，减少误触。`0.7.7-button-stop`
仅在新触摸从当前已显示的首页停止按钮严格区域内开始时立即撤销输入，并消耗
本次触摸至松开。触碰状态、电量、空白处，或从外部滑入停止按钮，均不能撤销
授权或取消正在进行的动作。旧画面不能提供停止目标。实体正面按键/MCP 停止、
显示/输入断连、触摸读取错误的保护性停止及同次触摸不能开启均保持。前文任意
触屏停止条目描述 `0.7.6`，由此新约定替代。

修改固件前扩展实际函数宿主场景：空白/状态/电量触碰、滑入、控制开启和忙碌时
按钮停止、旧显示画面、读取失败、消耗至松开。先对 `0.7.6` 运行，复现空白触碰
撤销授权，再对修改后运行。复用布局/电量检查、固定 SDK 编译打包及共用布局
双语渲染，保留报告、执行器、无线、安全、存储和实体停止函数。实际按钮命中、
停止延迟和防误触效果另行实机验收；本次源码修改不授权设备执行。
