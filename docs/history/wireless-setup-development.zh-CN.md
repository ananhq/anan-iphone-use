# 无线配网验收范围

[English](wireless-setup-development.md) · 简体中文

实现前确认：首次配置和手动管理网络使用临时 WPA2 热点；保存最多 5 个
2.4 GHz 网络并自动轮换连接；USB 与 Wi-Fi 共用 `stopwatch.local` HTTP MCP 地址。
保留 USB、七个工具、配对、明确控制授权、停止、输入时序及不重放动作。

离线场景：迁移旧单网络记录并保留密码，验证存储边界，更新同名网络，
第六个网络拒绝保存且不覆盖旧记录，单独删除网络；网页以文本渲染扫描结果，
不存储密码，热点关闭前可导出固定域名配置；Host/Origin 仍限定实际本地接口。
mDNS 使用已锁定 SDK 中的 lwIP，并列保留完整 Verisure BSD 通知及既有 lwIP 通知，不增加外部包。

实机验收另行授权：无网络首次启动，连接屏幕显示的 WPA2 热点，自动 DHCP，
网页与设备物理配对，扫描保存，关闭热点前复制配置，手机返回局域网及 BLE；
重复 USB 流程；重启保留；两个已存网络之间换场所；错误密码回退；列表满和
单独删除；配网超时和取消；iPhone/Mac 在各接口解析 `.local`；重名冲突；
网段重叠；断连时停止且不恢复授权或重放。不提供互联网转发或常驻热点输入。
此最小实现暂缓二维码和自动门户，使用屏幕密码及 Safari 地址。

编译及离线场景不能证明射频共存、DHCP/mDNS 实际交付、手机操作成功、
真实切网延时或耐久性。

## 仅 IPv4 的探测回归范围

修正前提取锁定 SDK 的实际 `mdns_probe_and_announce` 函数，模拟 IPv4 发送成功但 IPv6 不可用、双栈发送成功、无 IPv4 三种场景。旧函数在仅 IPv4 时不能完成探测，解释一个源码层面的失败条件。修正仅在没有有效 link-local IPv6 地址时跳过 IPv6 探测，保留三次 IPv4 探测与冲突检测。对生成的 SDK 适配版本运行同一场景，编译/打包并保持输入/schema/USB 文件；授权重刷后另行对比 Safari 的数字 IP 与 `.local` 访问，不宣称已测定手机端根因。

## 二维码验收范围

实现前定义：编码合成 WPA2 名称/密码，独立解码生成图像得到准确 Wi-Fi 载荷；拒绝空/无效名称或短密码并清除旧结果；转义分隔符；圆屏完整绘制四个模块的白色静区，并独立解码完整静态预览。保留 WPA2、DHCP、配对及热点超时/停止。手机相机识别及实际加入另属设备验收。
