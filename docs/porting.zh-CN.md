# 板型适配指南与 Prompt

[English](porting.md) · 简体中文

当前只支持 StopWatch。并非所有 ESP32 都支持可配置的原生 USB Device；用于下载的 USB-UART 口不一定连接原生 USB。不要把 StopWatch 镜像烧到其他板型。

修改前收集准确芯片/板名/版本、原理图、USB D+/D−/供电走线、Flash/PSRAM、下载步骤、电源芯片/寄存器、按钮/有效电平、屏幕/触摸驱动和许可；逐项对照官方资料。区分可迁移的 TCP/解析/HID 与板级供电/停止映射；本次迁移不加入板型抽象。

先保留源码检查点及 ANAN1 行为，提出板级修改方案并确认，再编译/打包并记录哈希。编译不能证明 USB 枚举、停止可靠性或坐标正确；提前定义合成真机场景，烧录/输入前另获授权。屏幕适配放在基线及 MCP 阶段之后，不能影响心跳、停止或报告释放；保留来源声明并逐文件注明复用。
