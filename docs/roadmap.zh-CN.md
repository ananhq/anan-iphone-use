## 并行开发

固件、协议和板级文档归本仓库；Anan 管手机采屏、连接、工具、授权、后台及模型。开工前读 AGENTS.md 和快照，迁移期间保留原输入 hash，不把固件重新复制回 Anan。ANAN1 变更先协调客户端并确认，不默认引入 submodule/下载服务。

通过基线门槛后，可按文件所有权/worktree 并行研究。MCP 复用当前 HID 核心；截图/observe 是客户端能力，不是设备工具。USB 子网不会自动让电脑/远程 Agent 可达。Anan 当前 MCP 只接受 HTTPS，选协议前重新核对其固定 SDK 支持范围；不能假定 HTTP `/mcp` 已兼容。授权、所有权、停止、心跳、长度/并发/Origin 及取消/无重放规则需要确认方案。本次没有选择 MCP 版本/服务端/UI。

设备 UI 可以展示真实连接/动作/错误/停止；思考和任务状态需要新客户端显示契约，显示消息不能授予或延长控制许可。硬件具备触摸屏，但固件不含两个驱动；尚未批准图形库/动画。

## 贡献与发布

外部贡献先约定具体 issue/范围，保留来源声明；更新相关英中文档，执行适当编译/静态检查，设备/E2E 按任务授权。公开前补来源/依赖声明和最终地址，据实验说明兼容性，并取得发布授权。拆分不表示同意改许可证。
