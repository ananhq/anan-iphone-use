连接 Wi-Fi


首次通过 USB 配置 2.4 GHz Wi-Fi。手机、电脑和设备加入同一局域网。无线输入在设备“设置 → 输入方式”选择 BLE，并在手机配对 Anan StopWatch。
















复制配置，粘贴到 Anan 的 MCP 配置导入页，或其他支持 HTTP MCP 的客户端。







下载 JSON

手机导入后，在设备点“完成 返回首页”，再点“开始控制”。点击设备“停止控制”或按实体键可停止；触碰其他位置不停止。屏幕观察由客户端提供。
